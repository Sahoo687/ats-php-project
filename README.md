How to Run Your Project
1.	Put these files into your local server directory (e.g., htdocs/ats in XAMPP or var/www/html/ats).
2.	Create a MySQL database named php_ats_db and execute the SQL schema from Phase 1.
3.	Point your browser to http://localhost/ats/index.php.
4.	Test posting a job, opening the applicant portal (apply.php?job_id=1), uploading a resume, and managing pipeline statuses in real-time.
